## 🧭 Visão Geral

Este repositório documenta meu **Plano de Carreira em Dados**, construído a partir de um mapeamento estruturado de perfil, objetivos e estratégias de transição para a área de **Análise de Dados e Inteligência Artificial**.

A proposta inclui:
- Diagnóstico de perfil profissional  
- Definição de objetivos de carreira  
- Roadmap de estudos  
- Aplicação prática com projetos
